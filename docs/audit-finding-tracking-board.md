## Status Definitions
- **Open:** Acknowledged but no patch yet.
- **In Review:** Patch submitted, awaiting maintainer approval.
- **Fixed:** Patch merged to `dev`.
- **Verified:** Re-tested by internal or external security reviewer.
- **Explicitly Accepted:** Will not fix (risk accepted, documented in threat model).
